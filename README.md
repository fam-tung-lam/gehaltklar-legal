# GehaltKlar Legal

Public legal information for the GehaltKlar mobile application.

The published privacy policy is available in German, English, Russian,
Ukrainian, and Vietnamese. It does not use cookies, analytics, tracking, or
third-party scripts.

## Language selection

Use the `lang` query parameter to open the page in a specific language:

- `?lang=de` — German
- `?lang=en` — English
- `?lang=ru` — Russian
- `?lang=uk` — Ukrainian
- `?lang=vi` — Vietnamese

Without the query parameter, the page uses a supported browser language and
falls back to German. Regional browser language tags such as `ru-RU`, `uk-UA`,
and `vi-VN` resolve to their supported base language. The sticky language
switcher remains visible while scrolling and updates the content and URL without
reloading the page.
